India Temple Heritage & Pilgrimage Information Portal

A centralized digital directory and information portal that provides authentic, comprehensive, and location-based insights into Indian temple heritage, historical contexts, daily rituals, and essential visitor guidelines. This platform aims to preserve cultural data while enabling seamless pilgrimage planning for tourists, researchers, and devotees.

🚀 Key Features

👥 User-Facing Features
* Dynamic Search & Filtering: Case-insensitive search across temple names, deities, cities, or states. Custom dropdown filters for instant exploration.
* Heritage Profile Pages: Tabbed UI interface dividing complex temple insights into three clean categories:
* History & Significance: Deep architectural origins, myths, and historic timelines.
* Rituals & Timings: Comprehensive active daily pooja charts with detailed morning/evening hours.
* Visitor Guidelines: Dynamic tracking of dress codes, local entry pricing rules, and photography rights.
* Pilgrimage Circuits: Aggregated data modules showcasing popular historical routes (e.g., 12 Jyotirlinga, Chhota Char Dham).

🛠️ Admin Management System
* Secure Data Management: Dedicated interface for trusted administrative heads to add, modify, or erase temple profiles.
* Validation Control: Clean verification flow checks raw input schemas before letting data surface live onto the application platform.

## 🛠️ Technology Stack

Frontend:
* React.js (Functional components, hooks, custom state matrices)
* React Router DOM (Dynamic slug/ID parameters route mapping)
* Tailwind CSS (Responsive mobile-first styling system)
* Axios (Custom instance base-URL connection handlers)

Backend:
* Node.js & Express.js (RESTful API architecture & routing)
* Mongoose (Schema structures enforcement & database interaction layers)
  
Database:
* MongoDB Atlas (Cloud NoSQL database storage registry)
